# AI Powered GitHub Pull Request Risk Intelligence

A data science and AI project for analysing GitHub pull
requests using machine learning, a local large language model,
Retrieval Augmented Generation and agentic RAG.

## Project Objective

The project aims to identify high risk pull requests, predict merge delays,
retrieve relevant repository policies and generate evidence grounded review
recommendations.

## Planned Capabilities

- GitHub REST API data ingestion
- Historical pull request analytics
- Data quality validation
- Merge delay prediction
- Explainable engineering risk scoring
- Local LLM based PR analysis
- Repository policy retrieval using RAG
- Agentic RAG with controlled tool selection
- Static security and code quality analysis
- LLM, RAG and agent evaluation
- Executive engineering analytics

## Technology Stack

- Python
- Jupyter Notebook
- GitHub REST API
- Pandas
- Scikit-learn
- Ollama
- Sentence Transformers
- FAISS or Chroma
- LangGraph
- Bandit
- Ruff

## Project Status

Project setup and environment configuration are currently in progress.

## Cost and Deployment

The LLM, embeddings, vector database and machine learning pipeline run locally. The project does not require a paid LLM API or cloud deployment.
